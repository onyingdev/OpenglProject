folder structure:

 /assets            #images, models, sound, etc... this is where to place everything to program games
    /shaders
    /textures
    /scripts

 /app
    /bin            #release folder, where the actual application is

 /build             #local build objects folder

 /documentation     #documentation stuff

 /include
    /Core           #helpers, application, input manager, window. Using only the core functions the app should work
    /Render       #opengl, vertex buffer, shader loader. Manages all the graphical API config and render functions.
    /UI             #UI stuff
    /Components     #basic components for building GameObjects

 /src
    /Core
    /Render
    /UI
    main.cpp

 /vendor            #third party software
    /glad
    /GLFW
    /glm


    One caveat I documented in the code: the bounds test uses the body's center, not its full footprint — 
    so a box whose center slides past the edge will drop off (its overhanging half won't keep it up). 
    That's the cheap first-pass behavior; if you need bodies to balance on edges, widen halfExtents or 
    add a wall collider. Say the word if you'd rather I expand the test to account for the body's lateral
     radius so it clamps at the true edge.
